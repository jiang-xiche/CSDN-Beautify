# CSDN美化 - 旧版两栏+自动展开+去广告+净化剪贴板+屏宽自动适配

[![License: CC BY-NC 3.0](https://img.shields.io/badge/License-CC%20BY--NC%203.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/3.0/)
[![Version](https://img.shields.io/badge/version-2.1-blue.svg)](https://github.com/jiang-xiche/CSDN-Beautify)
[![Greasy Fork](https://img.shields.io/badge/Greasy%20Fork-安装-green.svg)](https://greasyfork.org/zh-CN/scripts/373974)

> 让CSDN博客回归经典阅读体验！

## 📋 功能特性

✅ **经典两栏布局** - 保留作者信息和顶部导航栏，去掉右边评论区  
✅ **内容自动展开** - 折叠内容自动展开，无需点击"阅读全文"  
✅ **屏宽自动适配** - 响应式设计，适配不同屏幕尺寸（v2.0重大更新）  
✅ **广告移除** - 去掉推广广告和侧边工具栏  
✅ **界面净化** - 移除未登录提示和VIP免广告按钮  
✅ **剪贴板净化** - 复制内容无版权后缀

## 🚀 快速开始

### 安装步骤

1. **安装脚本管理器**（选择其一）
   - [Tampermonkey](https://www.tampermonkey.net/) (推荐)
   - [Violentmonkey](https://violentmonkey.github.io/)
   - [Greasemonkey](https://www.greasespot.net/) (仅Firefox)

2. **安装脚本**
   - [从 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/373974)
   - 或从本仓库手动安装 `CSDN-Beautify-latest.js`

3. **开始使用**
   - 访问任意CSDN博客文章页面
   - 脚本自动生效，享受清爽阅读体验！
